# Code Map (read this instead of re-exploring)

- **Two packages, split by role** (both in `backend/src/`, both packaged): `fin_terminal` is canonical for **ingestion** (connectors, `schemas.py`, `config.Settings`, `resilience.SourceGuard`, `evidence.EvidenceLog`, `vectorstore/`, CLI `python -m fin_terminal.ingest`). `stop_loss` is canonical for the **product**: `agents/` (LangGraph analysis), `analytics/`, `retrieval/`, `api/` (FastAPI) — it imports from `fin_terminal` (exception: `fin_terminal.config` subclasses the legacy `stop_loss.config.Settings` and uses `stop_loss.symbols`).
- **Legacy, don't extend**: `stop_loss/ingestion/` (unimplemented sync providers + runner), `stop_loss/__main__.py` CLI, `stop_loss/domain/` lowercase-enum models (see `docs/DECISIONS.md`).
- **Analysis graph**: `stop_loss/agents/graph.py::build_analysis_graph` — `START → coordinator → {market, news, impact, analogs} → quant → hedging → audit → END`. Nodes in `agents/nodes.py::build_nodes`; portfolio mode (`portfolio=True`) swaps in `agents/portfolio_nodes.py::build_portfolio_nodes` with the same node names. State: `agents/state.py::AnalysisState`. Run by `agents/service.py` with `AsyncSqliteSaver`.
- **Ingestion graph**: `fin_terminal/ingestion/graph.py::build_graph` — `plan_sources → <per-source stream nodes> → write_evidence → report`.
- **API**: `stop_loss/api/app.py` (`stop-loss-api`): `/chat` + SSE `/chat/runs/{id}/events` (legacy custom events), `POST /runs` (SSE typed node lifecycle via `astream_events`) + `GET /runs/{id}` (SQLite replay), `/market/*`, `/portfolio/*`, `/news/feed`, `/feedback`, `/assets/search`.
- **Frontend** (`frontend/`): Next.js 14 App Router, React 18, TypeScript, Tailwind 3, Recharts, Firebase auth, Playwright e2e. Pages: `/` (entry), `/login`, `/onboarding`, `/dashboard`, `/chat`. `app/api/**` route handlers proxy to the FastAPI backend (`lib/server/proxy.ts`); chat streaming in `lib/chat/` (`sse.ts`, `reducer.ts`, `useChatStream.ts`); UI in `components/chat/` and `components/portfolio/`.
- **Data**: `data/` (raw/processed NSE, macro, calamity, news CSVs) and `backend/data/` (SQLite + `evidence.jsonl`) are off-limits to read; loaders live in `stop_loss/retrieval/datasets.py`, `stop_loss/analytics/{analogs,event_windows}.py`, root `download_*.py`, `scripts/preprocess_data.py`.
- **Checks**: `make check` = ruff lint + ruff format --check + pytest (`backend/tests/{fin_terminal,terminal,unit}`, fixtures in `backend/tests/fixtures/`).
- **Run events (SSE)**: models in `stop_loss/agents/run_events.py` (only file to edit; `make schema` → `frontend/types/run-events.schema.json`, drift-tested). `agents/event_stream.py` translates `astream_events` v2 → run_started/node_started/node_finished/node_error/final_answer; `api/graph_runs.py` (RunRegistry subclass) persists via `api/run_store.py` (`RUNS_DB_PATH`).
- **Phase 0 (baseline)**: `make check` is green (Windows: `.tools/make.exe check`). Prompt modules `agents/llm.py` and `agents/portfolio_llm.py` are exempt from E501 (prompt text is kept verbatim).
  Offline tests expect `analogs` to be `unavailable` (no vector index), so ticker results are `partial` with `failed_agents == ["analogs"]`.
  The coordinator always forces `mode="analysis"`; follow-ups return a full `final` result, not a `reply`.
- **Phase 1 (live ingestion)**: `stop_loss/retrieval/live.py` (`LiveIngestor`, per-source tasks + `CircuitBreaker` + backoff; news/GDACS/USGS/weather → Pinecone `live` ns, history `Record` shape, `DocumentStore` dedupe), `source_health.py` (SQLite, read by `GET /health/sources`), `latency.py` (`make latency` → `docs/latency_report.md`).
  `HistoricalRetriever(embedder, adapter, "history", "live")` queries both namespaces, merges by score, tags `Hit.namespace` (also on analog outputs). CLI: `stop-loss-vectors live|latency`; Make: `live`, `latency`.
  Embeddings: `EMBEDDING_BACKEND=local` falls back to `OnnxEmbeddings` (fastembed, same bge-base vectors, self-cosine ≥ 0.999) when torch is absent; extra `onnx-embeddings`; `EMBEDDING_THREADS` (default min(8, cores)).
